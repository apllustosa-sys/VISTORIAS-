# Vistoria Pericial — AL Engenharia

Aplicativo de vistoria técnica para perícias judiciais de engenharia civil: dados do processo, patologias, quantitativos, relatório fotográfico com data e hora, medição de áreas por cômodo e relatório para download.

## Publicar no GitHub Pages
1. Envie todos os arquivos desta pasta para a raiz de um repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.
3. Após 1 a 2 minutos, o aplicativo fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Instalar no iPhone
Abra o endereço no **Safari** → Compartilhar → **Adicionar à Tela de Início**.

Os dados ficam salvos no próprio aparelho.
